### Featured Projects

**[Salon Booking Platform](https://github.com/shubhampuri264-cell/SalonWebsite)** · [Live at iconht.studio](https://iconht.studio)  
Built the booking system a new salon business launched on, from an empty repo to a live product. Customers pick a stylist, see real availability, and book without calling. `TypeScript` `Supabase` `Node.js`

**[Autonomous Code Review & Testing Agent](https://github.com/shubhampuri264-cell/Autonomous-Code-Review-Testing-Agent)**  
An agent that reads a repository, writes its own test suite, runs it inside a Docker sandbox, and opens a pull request with the results. No human in the loop. `LangGraph` `tree-sitter` `Docker` `Python`

**[AI Malware Detection App](https://github.com/shubhampuri264-cell/Malware-Detection-App)**  
Android app that scans APKs for malware entirely on the device. The neural network runs locally, so it works with no internet and no file ever leaves the phone. `React Native` `TensorFlow Lite` `TypeScript`

**[CS Career Navigator](https://github.com/shubhampuri264-cell/CareerNavigator)**  
An assessment tool that maps a student's skills and interests to a concrete career path, with reasoning from the Gemini API instead of a generic quiz result. `Python` `FastAPI` `Gemini API`

**[Distributed Risk Engine](https://github.com/shubhampuri264-cell/Distributed-Risk-Engine)**  
Pulls live market data, runs Monte Carlo simulations at scale, and exposes VaR and CVaR analytics through a CLI and a web dashboard. `Python` `NumPy` `Distributed Compute`
